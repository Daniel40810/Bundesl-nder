# Bundesländer Java

Java-Anwendung zur Darstellung und Verwaltung deutscher Bundesländer.

## Funktionen

- Anzeige deutscher Bundesländer
- Java Swing Oberfläche
- Karten- und Geodatenintegration
- Erweiterbar für Spatial- und GIS-Funktionen

## Voraussetzungen

- Java 21 oder neuer
- Apache Ant
- NetBeans

## Build

\`\`\`bash

ant clean

ant jar

\`\`\`

## Start

\`\`\`bash

java -jar dist/Bundeslaender.jar

\`\`\`
